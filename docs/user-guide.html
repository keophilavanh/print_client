Print Client

Print Client ແມ່ນໂປຣແກຣມທີ່ເຮັດວຽກຢູ່ໃນຄອມພິວເຕີຂອງຮ້ານ. ມັນຮັບງານພິມ (ໃບບິນ, ໃບສັ່ງອາຫານ) ຈາກ Print Service ຜ່ານອິນເຕີເນັດ ແລ້ວສົ່ງໄປພິມທີ່ເຄື່ອງພິມຂອງຮ້ານ.

Print Client runs on the shop's computer. It receives print jobs (receipts, kitchen orders) from Print Service over the internet and sends them to the shop's printers.

ແບ່ງປັນເຄື່ອງພິມໃນ WindowsShare the printer in Windows

Print Client ພິມຜ່ານຊື່ share ຂອງເຄື່ອງພິມ. ຖ້າເຄື່ອງພິມຍັງບໍ່ໄດ້ແບ່ງປັນ ໃຫ້ເຮັດຕາມນີ້:

Print Client prints through the printer's share name. If the printer isn't shared yet:

  1. ເປີດ Settings → Bluetooth & devices → Printers & scannersOpen Settings → Bluetooth & devices → Printers & scanners
  2. ກົດເລືອກ POS-80C → Printer propertiesSelect POS-80C → Printer properties
  3. ແຖບ Sharing → ໝາຍ Share this printer → ຊື່ share: POS2026 → OKSharing tab → tick Share this printer → share name POS2026 → OK

ກວດວ່າ share ມີແລ້ວ (ເປີດ Command Prompt):

Check that the share exists (in Command Prompt):

net view \\localhost

ຕ້ອງເຫັນແຖວ POS2026 Print POS-80C.

You should see a line POS2026 Print POS-80C.

ຊື່ share ບໍ່ສົນໃຈຕົວພິມໃຫຍ່-ນ້ອຍ: POS2026 ແລະ pos2026 ແມ່ນອັນດຽວກັນ. Share names aren't case-sensitive: POS2026 and pos2026 are the same.

ຕິດຕັ້ງ Windows ServiceInstall the Windows service

ເມື່ອຕິດຕັ້ງເປັນ service ແລ້ວ Print Client ຈະເລີ່ມເອງທຸກຄັ້ງທີ່ເປີດຄອມ ແລະ ເລີ່ມໃໝ່ເອງພາຍໃນ 10 ວິນາທີ ຖ້າມັນຢຸດເຮັດວຽກ — ບໍ່ຕ້ອງເປີດໜ້າຕ່າງໃດໆໄວ້.

As a service, Print Client starts with Windows and restarts itself within 10 seconds if it stops — no window needs to stay open.

  1. ປິດໜ້າຕ່າງ npm start ຫຼື npm run dev ທີ່ເປີດຢູ່ (ຖ້າມີ).Close any open npm start or npm run dev window.
  2. ກົດສອງເທື່ອທີ່ install-service.bat ໃນໂຟນເດີ D:\sambaPOS\print_client.Double-click install-service.bat in D:\sambaPOS\print_client.
  3. ກົດ Yes ເມື່ອ Windows ຖາມສິດ Administrator.Click Yes when Windows asks for administrator rights.
  4. ລໍຖ້າຈົນເຫັນ [OK] "Print Client" is installed and running ແລ້ວກົດປຸ່ມໃດກໍ່ໄດ້ເພື່ອປິດ.Wait for [OK] "Print Client" is installed and running, then press any key to close.
  5. ເປີດ http://localhost:3020 ເພື່ອກວດສະຖານະ.Open http://localhost:3020 to check the status.

ຕົວຕິດຕັ້ງເຮັດຫຍັງແດ່What the installer does

  1. ກວດ Node.js 22+Checks for Node.js 22+
  2. ຖອນ service ເກົ່າອອກ (ຖ້າມີ)Removes an older Print Client service, if any
  3. ກວດວ່າ port 3020 ຫວ່າງChecks that port 3020 is free
  4. npm install (ຖ້າຍັງບໍ່ມີ node_modules) ແລະ npm run buildnpm install (if node_modules is missing) and npm run build
  5. ດາວໂຫຼດ WinSW (ໂປຣແກຣມທີ່ເຮັດໃຫ້ Node.js ເຮັດວຽກເປັນ service) ໄປໄວ້ທີ່ service\PrintClient.exeDownloads WinSW (the tool that runs Node.js as a service) to service\PrintClient.exe
  6. ຕິດຕັ້ງ ແລະ ເລີ່ມ service ດ້ວຍບັນຊີ SYSTEM, ແລ້ວກວດວ່າ Dashboard ຕອບກັບInstalls and starts the service as SYSTEM, then checks that the dashboard answers
ອັບເດດໂປຣແກຣມ: ຫຼັງຈາກປ່ຽນໂຄດ ໃຫ້ກົດ install-service.bat ອີກຄັ້ງ — ມັນຈະ build ແລະ ຕິດຕັ້ງໃໝ່ໃຫ້. Updating: after the code changes, run install-service.bat again — it rebuilds and reinstalls.

ຕິດຕັ້ງ WinSWInstall WinSW

WinSW (Windows Service Wrapper) ແມ່ນໂປຣແກຣມ open-source ຂະໜາດນ້ອຍທີ່ເຮັດໃຫ້ Node.js ເຮັດວຽກເປັນ Windows service ໄດ້. ມັນເລີ່ມ Print Client ເມື່ອເປີດຄອມ, ເລີ່ມໃໝ່ເມື່ອມັນຢຸດ ແລະ ບັນທຶກ log.

WinSW (Windows Service Wrapper) is a small open-source tool that lets Node.js run as a Windows service. It starts Print Client with Windows, restarts it if it stops, and writes the log files.

ໄຟລ໌ FileWinSW.NET461.exe (≈ 640 KB)
ຕ້ອງການ Needs.NET Framework 4.6.1 ຂຶ້ນໄປ — ມີຢູ່ແລ້ວໃນ Windows 10 ແລະ 11.NET Framework 4.6.1 or newer — already part of Windows 10 and 11

ຢ່າໃຊ້ເວີຊັນ 3.0 (alpha) — ມັນເປັນເວີຊັນທົດລອງ ແລະ ໃຊ້ຮູບແບບການຕັ້ງຄ່າຕ່າງກັນ. Don't use version 3.0 (alpha) — it's a test version and uses a different config format.

ແບບອັດຕະໂນມັດ (ແນະນຳ)Automatic (recommended)

ບໍ່ຕ້ອງເຮັດຫຍັງ: install-service.bat ຈະດາວໂຫຼດ WinSW ໃຫ້ເອງ ຖ້າຍັງບໍ່ມີ service\PrintClient.exe. ຖ້າມີແລ້ວ ມັນຈະໃຊ້ໄຟລ໌ເດີມ ບໍ່ດາວໂຫຼດໃໝ່.

Nothing to do: install-service.bat downloads WinSW by itself when service\PrintClient.exe is missing. If the file is already there, it reuses it.

ແບບດ້ວຍມື (ຄອມບໍ່ມີອິນເຕີເນັດ ຫຼື ດາວໂຫຼດບໍ່ໄດ້)Manually (no internet, or the download failed)

  1. ໃນຄອມທີ່ມີອິນເຕີເນັດ ດາວໂຫຼດ WinSW.NET461.exe (ຫຼື ເຂົ້າ ໜ້າ release v2.12.0 ແລ້ວເລືອກ WinSW.NET461.exe).On a computer with internet, download WinSW.NET461.exe (or open the v2.12.0 release page and pick WinSW.NET461.exe).
  2. ສ້າງໂຟນເດີ service ໃນ D:\sambaPOS\print_client (ຖ້າຍັງບໍ່ມີ).Create a service folder in D:\sambaPOS\print_client if it doesn't exist.
  3. ສຳເນົາໄຟລ໌ໄປໄວ້ໃນໂຟນເດີນັ້ນ ແລະ ປ່ຽນຊື່ເປັນ PrintClient.exe. ຊື່ຕ້ອງກົງກັບ id ຂອງ service.Copy the file into that folder and rename it to PrintClient.exe. The name must match the service id.
  4. ກົດຂວາທີ່ PrintClient.exe → Properties → ຖ້າມີ Unblock ຢູ່ລຸ່ມສຸດ ໃຫ້ໝາຍ ແລ້ວກົດ OK (Windows ບລັອກໄຟລ໌ທີ່ດາວໂຫຼດມາ).Right-click PrintClient.exe → Properties → if Unblock appears at the bottom, tick it and click OK (Windows blocks downloaded files).
  5. ກົດ install-service.bat. ມັນຈະຂ້າມການດາວໂຫຼດ, ສ້າງ PrintClient.xml ແລະ ຕິດຕັ້ງ service.Run install-service.bat. It skips the download, writes PrintClient.xml and installs the service.

ໄຟລ໌ຕັ້ງຄ່າ PrintClient.xmlThe PrintClient.xml config file

WinSW ອ່ານ service\PrintClient.xml (ຊື່ດຽວກັບ .exe). install-service.bat ສ້າງໄຟລ໌ນີ້ໃໝ່ທຸກຄັ້ງ — ບໍ່ຕ້ອງແກ້ໄຂເອງ. ເນື້ອໃນໃນເຄື່ອງນີ້:

WinSW reads service\PrintClient.xml (same name as the .exe). install-service.bat rewrites it every time — no need to edit it. On this computer it contains:

<service>
  <id>PrintClient</id>
  <name>Print Client</name>
  <description>Receives print jobs from Print Service and sends them to the shop printers.</description>
  <executable>C:\Program Files\nodejs\node.exe</executable>
  <arguments>--env-file-if-exists=.env --disable-warning=ExperimentalWarning dist\server.js</arguments>
  <workingdirectory>D:\sambaPOS\print_client</workingdirectory>
  <startmode>Automatic</startmode>
  <stoptimeout>15 sec</stoptimeout>
  <onfailure action="restart" delay="10 sec"/>
  <resetfailure>1 hour</resetfailure>
  <logpath>D:\sambaPOS\print_client\service\logs</logpath>
  <log mode="roll-by-size">
    <sizeThreshold>10240</sizeThreshold>
    <keepFiles>5</keepFiles>
  </log>
</service>
  • startmode Automatic — ເລີ່ມເອງເມື່ອເປີດຄອມstarts with Windows
  • onfailure restart 10 sec — ເລີ່ມໃໝ່ພາຍໃນ 10 ວິນາທີ ຖ້າຢຸດເອງrestarts within 10 seconds if it stops
  • log roll-by-size — log ໄຟລ໌ລະ 10 MB, ເກັບ 5 ໄຟລ໌10 MB log files, 5 kept

  2. ແທນ service\PrintClient.exe ດ້ວຍໄຟລ໌ໃໝ່ (ປ່ຽນຊື່ເປັນ PrintClient.exe), ຫຼື ລຶບມັນອອກເພື່ອໃຫ້ຕົວຕິດຕັ້ງດາວໂຫຼດ 2.12.0 ໃໝ່.Replace service\PrintClient.exe with the new file (renamed to PrintClient.exe), or delete it so the installer downloads 2.12.0 again.
  3. ກົດ install-service.bat.Run install-service.bat.

ການລອງພິມໃໝ່ອັດຕະໂນມັດAutomatic retries

ຖ້າພິມບໍ່ສຳເລັດ ງານຈະລອງໃໝ່ເອງ: ລໍຖ້າ 10 ວິນາທີ ແລ້ວເພີ່ມເປັນສອງເທົ່າແຕ່ລະຄັ້ງ ສູງສຸດ 5 ນາທີ, ລອງໄດ້ສູງສຸດ 10 ຄັ້ງ. ເມື່ອເຄື່ອງພິມກັບມາ online ງານທີ່ລໍຖ້າຈະພິມທັນທີ. ຫຼັງ 10 ຄັ້ງ ງານຈະເປັນ Failed — ກົດ Retry ເພື່ອພິມໃໝ່.

A failed job retries on its own: first after 10 seconds, doubling each time up to 5 minutes, at most 10 attempts. When the printer comes back online, waiting jobs print immediately. After 10 attempts the job is Failed — press Retry to print it again.
